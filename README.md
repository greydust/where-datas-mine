# Where Datas Mine

An independent **Where Winds Meet** gameplay reference.

[Browse Where Datas Mine](https://greydust.github.io/where-datas-mine/)

- **Items:** Gear Tier 91, 96 and 100 equipment, base stats, Initial and Tuning Affix maximums with Relayed (94%) values, and Attunement maximums.
- **Inner Ways:** Normal Inner Way effects by tier, with stat values for Solo Levels 16–18.
- **Martial Arts:** Normal martial arts and talent effects at Tiers 13–14, with a shared Tier selector.
- **Formula:** Critical, Affinity, Normal and Abrasion rates, forced outcomes, avoidance and Affinity conversion.
- **JSON:** [items](data/items.json), [Inner Ways](data/inner-way.json), and [Martial Arts](data/martial-arts.json).
