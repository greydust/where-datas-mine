# Where Datas Mine

An independent **Where Winds Meet** gameplay reference.

[Browse Where Datas Mine](https://greydust.github.io/where-datas-mine/)

- **Items:** Gear Tier 91 and 96 equipment, base stats, Initial and Tuning Affix maximums with Relayed (94%) values, and Attunement maximums.
- **Item Sets:** Weapon, Armor, and Bow/Ring bonuses, with gear-tier stat comparisons.
- **Inner Ways:** Normal Inner Way effects by tier, with stat values for Solo Levels 16–17.
- **Martial Arts:** Normal martial arts and talent effects at Tier 13, with a shared Tier selector.
- **JSON:** [items](data/items.json), [Item Sets](data/item-sets.json), [Inner Ways](data/inner-way.json), and [Martial Arts](data/martial-arts.json).
